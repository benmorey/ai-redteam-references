# AI Red-Team References

A reference collection for **authorized** AI red-teaming and defensive security
research — the kind done on sandboxed platforms, in CTF competitions, in
sanctioned pentests, and against your own systems. The goal of this material is
to catalog how tool-using agents and aligned models fail so that they can be
built not to.

## Contents

- [`jailbreaking-resources.md`](jailbreaking-resources.md) — a curated reading
  list of taxonomies, agent-attack benchmarks, model-internals research, and
  sandboxed practice platforms (OWASP, MITRE ATLAS, NIST, AgentDojo, and more).
- [`llm-jailbreak-redteam-references-2026.md`](llm-jailbreak-redteam-references-2026.md)
  — a broader index of repositories, papers, lab reports, researchers, and
  competition platforms in the jailbreak / prompt-injection space.

## Scope and intent

For authorized testing and defensive research only. These references describe
how tool-using agents and aligned models fail so they can be built to resist —
not a license to point techniques at systems you don't own.

> Note: the second list aggregates third-party citations and statistics that
> have not all been independently verified. Check each source before relying on
> it.
